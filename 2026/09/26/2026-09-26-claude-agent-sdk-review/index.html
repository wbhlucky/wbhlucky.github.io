Claude Agent SDK 技术复盘：模块、Skill、自定义 Tool 与自研边界

一、SDK 核心模块概览

Claude Agent SDK 源码结构并不复杂，核心模块如下：

模块 职责
client.py 交互式客户端 ClaudeSDKClient，支持多轮、有状态、双向通信
query.py 一次性查询入口 query()，单向、无状态、适合批处理
types.py 所有配置、消息、Tool、Hook、MCP、Skill、Agent 的类型定义，是配置总入口
_errors.py SDK 异常定义
_internal/ 内部实现：client、query、transport（subprocess_cli）、message_parser、session_resume 等

关键结论： Claude Agent SDK 不是一个"从零实现 Agent Loop 的纯 Python 框架"，它本质上是在 Python 进程里提供控制接口，驱动随包提供的 Claude Code CLI/Harness。当前最新 release 为 v0.2.159（2026-09-23），捆绑 CLI 2.1.281。

二、query() vs ClaudeSDKClient 对比

维度 query() ClaudeSDKClient
通信方式 单向 双向
状态 无状态 有 Session 状态
交互模式 一次性 多轮 follow-up
支持中断 不支持 支持 interrupt
适用场景 一次分析、CI、批处理、自动任务 聊天、多轮交互、中途打断、动态追加消息

query() 执行流程：程序 → query(prompt, options) → Claude Agent → 不断 Tool Call → 不断 Tool Result → 最终结果。

ClaudeSDKClient 执行流程：connect → query → receive_response → query → receive_response → interrupt → 继续。

client.py 最终也会创建内部 Query，把 hooks、agents、MCP、skills 等配置传进去。

三、types.py — 配置总入口

ClaudeAgentOptions 是 Agent Runtime 的"装配配置"，包含以下核心能力：

配置项 作用
tools 控制可用的 built-in tools
allowed_tools 控制哪些工具可以自动放行
system_prompt 可继承 Claude Code 默认 system prompt
mcp_servers 配置 MCP 服务器
agents 定义 Subagent
skills 开启 Skill
plugins 插件配置
hooks 生命周期拦截
permission_mode 权限控制
sandbox Bash 沙箱约束
session 会话管理
model 模型配置
cwd 工作目录

四、内置工具（Built-in Tools）

SDK/Claude Code Harness 内置的核心工具：

工具 功能
Read 读取文件内容
Write 写入文件
Edit 编辑文件
Bash 执行 shell 命令
Glob 文件模式搜索（找文件）
Grep 文本/正则搜索（找内容）
WebSearch 网络搜索
WebFetch 网页抓取

回答用户核心疑问： - 有没有最简单的文本搜索？→ 有 Grep（文件内容搜索）+ Glob（文件模式搜索） - 有没有 Shell？→ 有 Bash，且可通过 sandbox 配置约束 filesystem/network 行为

五、Skill 机制

SDK 提供的是"Skill 能力/加载机制"，不是"Skill 内容仓库"

Claude Agent SDK
├── Skill 的发现/加载机制   ✅
├── Skill 的调用机制       ✅
├── Skill 的渐进式披露机制 ✅
├── Skill 与 Agent Loop 集成 ✅
└── 具体 Skill 文件内容     ❌ 不由 SDK 本体统一提供

Skill 的具体来源

  • Claude Code 自带的 Skill
  • Anthropic / 官方 Skills 仓库（https://github.com/anthropics/skills）
  • Plugin 提供的 Skill
  • 自己写的 SKILL.md

使用方式

# 启用指定 Skill
ClaudeAgentOptions(skills=["trace-analysis"])

# 启用所有 Skill
ClaudeAgentOptions(skills="all")

skills 参数是启用/筛选已被发现的 Skill 的入口，不是内置 Skill 仓库。skills=None 时 CLI 默认 Skill 仍可能存在，skills=[] 才是隐藏所有 Skill listing。

Skill 文件结构

skill-name/
├── SKILL.md          # Skill 主体
├── references/       # 参考资料（可选）
├── scripts/          # 脚本（可选）
└── assets/           # 资源文件（可选）

六、RAG 能力

SDK 没有独立的 RAG 模块

  • 不会看到 ClaudeAgentOptions(rag=...) 这样的配置
  • SDK 核心能力聚焦于：Agent Loop、Tools、Skills、MCP、Subagents、Hooks、Sessions、Permissions、Context
  • 不包含 VectorDB、Embedding、Retriever、Reranker、RAG Pipeline

如何实现 RAG？

把 Retriever 做成 Tool。

Claude Agent
    ↓
memory_search(query="...")    ← 自定义 MCP Tool
    ↓
Retriever (SQLite / PostgreSQL + pgvector)
    ↓
Top-K memories
    ↓
Tool Result
    ↓
Claude 继续推理

这就是 Agentic RAG：SDK 提供 Agent 调工具的能力，自己的 Memory/RAG 系统负责"怎么检索"。

七、进程内定义自定义 Tool

SDK 支持在同一个 Python 进程内定义 Tool，然后变成 MCP Tool 提供给 Claude：

from claude_agent_sdk import tool, create_sdk_mcp_server

@tool("greet", "Greet a user", {"name": str})
async def greet_user(args):
    return {
        "content": [
            {"type": "text", "text": f"Hello {args['name']}!"}
        ]
    }

server = create_sdk_mcp_server(
    name="my-tools",
    version="1.0.0",
    tools=[greet_user]
)

# 注入到 SDK
ClaudeAgentOptions(mcp_servers={"tools": server})

八、从 0 到 1 搭建 Trace Agent 的步骤

Step 1：安装

pip install claude-agent-sdk

当前最新 release 0.2.159，Python 要求 3.10+，package 默认自带 Claude Code CLI。

Step 2：最简 Agent 示例

import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    async for message in query(
        prompt="读取当前项目，告诉我项目的入口在哪里。",
        options=ClaudeAgentOptions(
            cwd="D:/Users/Administrator/Desktop/DitingAgent-main",
            tools=["Read", "Glob", "Grep"],
        ),
    ):
        print(message)

asyncio.run(main())

此时已拥有：LLM + Agent Loop + Read + Glob + Grep。

Step 3：启用 Claude Code 完整 Harness

options = ClaudeAgentOptions(
    system_prompt={"type": "preset", "preset": "claude_code"},
    cwd=PROJECT_ROOT,
)

注意：新版不再默认自动带完整 Claude Code prompt，需显式配置。

Step 4：加入 Skill

目录结构：

DitingAgent/
└── .claude/
    └── skills/
        └── trace-analysis/
            ├── SKILL.md
            └── references/
                ├── rendering-analysis.md
                └── scheduling-analysis.md

配置：

options = ClaudeAgentOptions(skills=["trace-analysis"])

Step 5：接入 Trace Tools（MCP）

from claude_agent_sdk import tool, create_sdk_mcp_server

@tool("get_trace_overview", "Get a high-level trace overview", {"trace_path": str})
async def get_trace_overview(args):
    result = inspect_trace(args["trace_path"])
    return {
        "content": [{"type": "text", "text": result}]
    }

trace_server = create_sdk_mcp_server(
    name="trace", version="1.0.0", tools=[get_trace_overview]
)

options = ClaudeAgentOptions(mcp_servers={"trace": trace_server})

Step 6：接入 Memory Search（Agentic RAG）

@tool("memory_search", "Search trusted historical trace-analysis memories", {"query": str})
async def memory_search(args):
    memories = memory_runtime.search(args["query"])
    return {
        "content": [{"type": "text", "text": render_memories(memories)}]
    }

十、SDK vs 自研边界

Claude Agent SDK 帮你做的（无需自研）

能力 说明
Agent Loop SDK 原生提供
Tool Calling SDK 原生提供
Read / Write / Edit Built-in Tool
Bash Built-in Tool + sandbox 约束
Glob / Grep Built-in Tool
WebSearch / WebFetch Built-in Tool
Skill 原生 Skills 配置 + Skill Harness
MCP 原生支持 in-process MCP Server
Subagent agents / Agent tool
Hooks 完整 Hook 类型和生命周期
Permissions permission_mode 配置
Session ClaudeSDKClient + session/resume/fork
Context management 内置

需要自己写的（核心竞争力）

能力 说明
Trace Parser 业务领域解析器
Trace Domain Tools 领域专属 MCP Tool
Memory Store 记忆存储层
Memory Extraction 记忆抽取
Memory Consolidation 记忆整合
Memory Retrieval 记忆检索
Memory Rerank 记忆重排
Eval / Grader 评估体系
Evidence / Provenance 证据链
业务状态机 业务逻辑

十一、核心结论

DitingAgent 最合理的形态：Claude Agent SDK = 通用 Agent Runtime；自己的代码 = Trace Domain Runtime + Memory + Eval。

这比自维护一套平行的 ToolRegistry + Skill Hook + Agent Loop + Claude Adapter 更合理。核心竞争力应该是：

"Claude Agent SDK + Trace 专业能力 + 高质量 Memory + Evaluation"

而不是自己重新实现一个 Claude Code。

十二、FAQ 速查表

问题 答案
SDK 有没有 Skill？ 有，原生 skills 配置 + Skill Harness，但只提供机制不提供具体 Skill 文件
有没有 Tool？ 有，Read/Write/Edit/Bash/Glob/Grep/WebSearch/WebFetch
有没有简单文本搜索？ 有 Grep（内容搜索）+ Glob（文件搜索）
有没有 Shell？ 有 Bash
有没有 RAG 模块？ 没有独立的 RAG/VectorDB 模块
能不能做 RAG？ 能，把 Retriever/Memory Search 做成 MCP Tool
能不能自己写 Tool？ 能，支持 @tool + create_sdk_mcp_server()
能不能做 Subagent？ 能，agents / Agent tool
能不能做 Hooks？ 能，源码有完整 Hook 类型和生命周期
能不能做 Session？ 能，ClaudeSDKClient + session/resume/fork 能力
